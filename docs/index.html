Powerful Features

Everything you need to work with MQTT

🔌

Connection Management

Save and manage multiple broker connections. Quick switching between different environments with connection profiles.

📊

Real-Time Analytics

Monitor message rates, data volume, and topic statistics. Auto-refreshing dashboard with live metrics.

📈

Interactive Charts

Visualize numerical data from message payloads. Real-time line charts with multi-metric support and historical analysis.

🎯

Smart Message Filtering

Advanced search with full-text search, topic wildcards, time ranges, QoS, and user property filters.

🔄

Message Replay

Replay historical messages with configurable timing. Perfect for testing and reproducing scenarios.

📦

MessagePack Support

Full support for MessagePack encoding/decoding. Automatic detection and beautiful formatting of binary payloads.

🌳

Topic Tree Viewer

Hierarchical visualization of MQTT topics. Expandable tree view with message counts and last activity indicators.

💾

Message History

Persistent storage of all messages in SQLite database. Search, filter, and export message history.

📝

MQTT 5.0 Support

User properties, enhanced authentication, and request/response patterns. Full support for MQTT 5.0 features.

🎨

Modern UI

Clean, intuitive interface with dark mode support. Built with Ant Design for professional appearance.

📤

Export & Import

Export messages to JSON or CSV. Import connection profiles for easy sharing and backup.

⚡

High Performance

Handles thousands of messages per second. Efficient database storage with indexed queries.

Quick Start Guide

1

Download & Install

Download the installer for your platform and run it. The app will be ready in seconds.

2

Connect to Broker

Add your MQTT broker connection details. Supports username/password and TLS/SSL.

3

Subscribe & Publish

Subscribe to topics to receive messages. Publish messages with JSON, text, or MessagePack payloads.

4

Analyze & Monitor

Use the analytics dashboard, charts, and message history to understand your MQTT traffic.
